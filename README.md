# Scores: an offline score viewer for iPad

A home-screen web app that shows a song's score and tab and plays it along with the recording, with no server and no internet after the first visit.
Songs are NOT in this repository. They are private `.scorepack.json` files made on the owner's computer and opened from the Files app; they stay on the device.

Open the GitHub Pages address in Safari, then tap Share › Add to Home Screen.
